## UC5 – Stack Based Palindrome Checker

This use case validates whether a given string is a palindrome using the **Stack data structure**.  
Each character of the string is pushed into the stack and then popped in reverse order to compare with the original sequence.

### Goal
Use a stack to reverse characters and validate palindrome.

### Flow
1. Push characters into the stack.
2. Pop characters from the stack in reverse order.
3. Compare with the original string.
4. Display whether the string is a palindrome or not.

### Key Concepts Used
- **Stack (LIFO)** – Last In First Out principle.
- **Push Operation** – Inserts characters into the stack.
- **Pop Operation** – Removes characters from the stack.
- **Reversal Logic** – Stack reverses the order of elements.

### Data Structure
Stack
